# Demo Script — Codex Shortcuts Plugin

Target length: 75–90 seconds.

1. Show Stream Deck +, Stream Deck 7.1+, and the installed plugin/profile.
2. Show six Agent keys with task title, number, and color-and-shape status.
3. Press an Agent key once to open it in the background; double-press to bring
   Codex forward.
4. Show an available approval request and approve it from the deck.
5. Rotate Model, Reasoning, and Speed. Show the selected value applying after
   rotation stops. Tap to reload; long-press to reset.
6. Rotate Access through Ask, Delegate, Full, and Custom. Explain that Full
   changes Codex's approval/sandbox defaults and that the Access dial applies
   it after rotation stops without a separate confirmation dialog. Demonstrate
   only in a disposable environment, then return to Ask.
7. Press Voice once, speak briefly, show the local level animation, then press
   Voice again to let Codex transcribe and send.
8. Show the Property Inspector setting that disables accessibility-based
   controls. State that task status and configuration controls remain local and
   available.
9. Close with: “Independent third-party software by KAWAII, not affiliated
   with or endorsed by OpenAI or Elgato. No API key, maker telemetry, or
   maker-operated server.”

Do not show private task content, account details, credentials, filesystem
paths containing the username, or notification content.

Because this product depends on Stream Deck + hardware and the Codex
integration, attach the completed demonstration video to the review submission.
