コントロールの設定

準備中

役割を選ぶと、下に操作方法が表示されます。

誤操作を防ぎます

承認待ちのタスクがない場合、このキーは実行されません。

タスクの割り当て

Agent 1〜6の順に、最近使ったタスクを表示します。

CodexのタスクURL末尾にあるIDを貼り付けます。

キー操作をカスタマイズ

空欄なら標準の操作です。例: cmd+shift+r

使えるキー: A〜Z、数字、矢印、Enter、Escape

共通設定

OFFでも状態表示、Agentタスクを開く操作、設定ダイヤルの回転とタッチは使えます。ダイヤル押下の音声入力は停止します。

ONにした初回だけmacOSの許可が必要です

「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でStream Deckを許可します。
