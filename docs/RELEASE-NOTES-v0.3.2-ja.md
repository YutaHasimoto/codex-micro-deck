# Codex Shortcuts Plugin v0.3.2 リリースノート

リリース日: 2026年7月23日

v0.3.2では、Stream Deck +で選んだModel、Reasoning、Speed、Approval levelを、Codexで現在開いているタスクへ直接反映できるようにしました。設定ファイルへの保存だけで終わらず、既存タスクでも次のターンから新しい設定を使えます。

## 選択中タスクの次のターンへ反映

Codexで設定を反映したいタスクを開き、その後にダイヤルを操作します。現在のタスクが1件ならそのタスクを使い、現在タスクがない場合や複数ある場合はAgentキーで明示的に選んだタスクを反映先に使います。最新タスクを推測して勝手に変更することはありません。

- Model、Reasoning、Speedは、回転が止まって350ミリ秒後に自動適用します。
- 3つのダイヤルは、押すと待たずに即適用します。
- Approval levelは、候補を回して選んだ後、ダイヤルを押したときだけ確定します。
- 現在実行中のターン途中では切り替えず、そのタスクで次に開始するターンから新しい設定を使います。

同じ値は`~/.codex/config.toml`にも原子的に保存するため、新しく作るタスクの既定値にもなります。

## 反映結果が分かる表示

Deckは、タスクへの反映と既定値の保存を区別して表示します。

| Deck表示 | 意味 | 次にすること |
|---|---|---|
| `✓ Applied` | 現在のCodexタスクと、新規タスクの既定値へ反映済み | そのタスクで次のターンを開始する |
| `✓ Default` | 対象タスクがない。新規タスクの既定値だけ保存済み | 必要ならCodexで対象タスクを開く |
| `⚠ Select` | 現在タスクが複数あり、Agentキーが未選択。新規タスクの既定値は保存済み | 対象のAgentキーを選んで再適用する |
| `⚠ Default` | Codexへの反映に失敗。新規タスクの既定値は保存済み | Codexの起動を確認し、Agentキーを選び直して再適用する |

Codex側へ反映できなかった場合を`Applied`とは表示しないため、Deck上の値だけが変わって見える状態を判別できます。

## SpeedをStandardとFastの2択に整理

Speedダイヤルの候補を、現在のCodexで利用できるStandardとFastの2つに整理しました。左から3番目のダイヤルで切り替えます。

| 表示 | 動作 |
|---|---|
| Standard | 通常の速度。既定値 |
| Fast | 高速処理を使用 |

以前のバージョンにあったFlexは、現在の選択候補には表示しません。

## 再起動について

通常はCodexデスクトップの再起動は不要です。`✓ Applied`と表示された設定は、現在のターンが終わった後、次のターンから使われます。

Stream DeckのProperty Inspector自体が「未接続」になっている場合や、プラグイン更新後も古い表示のままの場合だけ、Stream Deckアプリを再起動してください。

## 更新後の確認

1. Codexデスクトップを起動します。
2. Codexで反映したいタスクを開きます。対象を確実に指定したい場合は、そのタスクのAgentキーを1回押します。
3. Model、Reasoning、Speedのいずれかを回し、350ミリ秒待ちます。Approval levelは目的の候補でダイヤルを押します。
4. Deckへ`✓ Applied`と`Current task · next turn`が表示されることを確認します。
5. 現在のターンが動作中なら完了を待ち、次のターンを開始します。
