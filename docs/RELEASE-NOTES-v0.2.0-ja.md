# Codex Shortcuts Plugin v0.2.0 リリースノート

リリース日: 2026年7月21日

v0.2.0は、Stream Deck +本体での見分けやすさ、設定画面の分かりやすさ、連続操作時の安定性を改善する更新です。

## アイコン中心のハードウェア表示

- 8キーから小さい文字ラベルをなくし、大きなLucideアイコンを中央に配置しました。
- 6つのAgentキーはロボットアイコンと1〜6の番号で区別します。
- Approveはチェック、Declineはバツのアイコンで区別します。
- Agentの状態を色だけでなく形でも示します。待機は円と点、作業中は円弧、完了・未確認はチェック、承認待ちは感嘆符、エラーは三角形、未割り当ては斜線入りの円です。
- 選択中のAgentは外枠の明滅で示します。
- 4つのタッチ領域は、Reasoning、Navigation、Commands、Composerごとに異なる大きなアイコンを表示します。下部の文字は現在値を示す1行だけに整理しました。
- Composerは通常時にメッセージ、Push-to-talk中にマイクのアイコンを表示します。

使用したLucideアイコンのライセンスは、プラグイン同梱の`THIRD_PARTY_NOTICES.md`に記載しています。

## 分かりやすい設定画面

- キーとダイヤルの設定を日本語化しました。
- 役割を選ぶと、「押す」「回す」「タップ」「長押し」で何が起きるかをその場に表示します。
- Agentのタスク割り当ては、必要なときだけ表示します。
- 自動割り当てがONの間は固定タスクID欄を隠し、設定の競合を防ぎます。
- 自動割り当てをOFFにしてタスクIDを空欄にすると、そのキーは未割り当てになります。以前のように最近のタスクへ暗黙に戻ることはありません。
- 承認と却下には、承認待ちタスクが選ばれていない場合は実行しないことを明記しました。
- タスクIDとカスタムキー操作の形式を入力中に検査し、不正な値は保存しません。
- 「保存中」「保存済み」「未接続」と、Stream Deckへの接続状態を表示します。
- 状態の更新間隔は1秒、2秒、5秒、10秒、30秒から選択できます。

## 安定性と誤操作防止

### Agentの順序を安定化

更新のたびにタスク一覧の順序へそのまま追従するのではなく、現在有効な割り当てを同じAgentキーに保持します。対象タスクが直近6件から外れたときだけ、その空いたキーを新しいタスクで補充します。

### 一時的な読取エラーでも表示を保持

CodexのSQLiteまたはWALを一時的に読めなかった場合は、最後に正常取得したタスク一覧を保持します。短い競合だけで6つのAgentキーが一斉に未割り当てになる現象を防ぎます。状態DB自体が存在しない場合は、古い情報を残さず未割り当てに戻します。

### 承認と却下の重複を防止

ApproveとDeclineは、先に選択したアンバーのAgentだけを対象にします。処理中の再入力をロックし、成功後は対象を作業中として即時表示し、5秒間は古い承認待ち状態が戻らないようにします。

承認または却下の実行時は、対象タスクの前面化成功を待ち、0.18秒の整定時間を置いてからReturnまたはEscapeを送ります。別のタスクやComposerへ入力が入る可能性を減らします。

### Push-to-talkの競合を防止

音声入力中のキーまたはダイヤルを所有者として記録します。同じ入力元から重複して押下イベントが届いた場合や、対応しない解放イベントが届いた場合は無視します。開始と停止を直列処理するため、短い連続操作で音声入力のON／OFFが逆転しにくくなりました。

### 複数tickを正しく処理

ダイヤル回転イベントに複数tickがまとめて届いた場合も、方向だけでなく回数を反映します。Reasoning、履歴移動、カーソル移動、カスタムキー操作を速く回した場合の取りこぼしを減らしました。1イベントで送る連続キー操作は安全のため最大8回です。

### 失敗箇所を安全に記録

操作に失敗した場合は、キーまたはダイヤルの役割、イベント種別、短いエラー理由をStream Deckのプラグインログへ記録します。タスクID、タスクURL、ユーザーフォルダのパス、複数行のプロセス出力は除去し、タスク本文やタイトルは記録しません。ハードウェア側にも警告表示を出します。

## macOSアクセシビリティ操作のON／OFF

設定画面の「Codexへのキー操作を有効にする」で、System Eventsを使うショートカットとコマンドパレット操作をまとめてON／OFFできます。

- ON: 承認、却下、履歴移動、Fast、Plan、Reasoning、Skillsなどを利用できます。初回はmacOSのアクセシビリティ許可が必要です。
- OFF: System Events操作を送信しません。状態表示とAgentキーのディープリンクは引き続き利用できます。

## 更新後の確認

1. Stream Deckアプリで「Codex Shortcuts Plugin」プロファイルを選びます。
2. 8キーが大きなアイコンで表示されることを確認します。
3. 4つのタッチ領域がそれぞれ異なるアイコンになっていることを確認します。
4. Agentキーを選び、設定画面に日本語の操作説明と保存状態が表示されることを確認します。
5. キー操作を使う場合は、「Codexへのキー操作を有効にする」がONで、macOSのアクセシビリティ許可が有効なことを確認します。
