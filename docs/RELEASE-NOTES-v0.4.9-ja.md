# Codex Shortcuts Plugin v0.4.9 リリースノート

## 音声入力終了時のアクセシビリティ操作

Codexは音声入力の開始後、入力欄の内部構造を動的に差し替えます。v0.4.9では、ChatGPTメインウインドウ内の安定した入力欄ルートから現在の子要素を探索し、終了側の「音声入力を停止」または「文字起こしして送信する」ボタンを操作するよう修正しました。

Codex側ですでに音声入力が終了して「音声入力」ボタンへ戻っていた場合も、その状態を検出してDeck側の録音表示を解除します。対象ボタンが見つからない場合や複数見つかった場合は推測でキー入力せず、安全に失敗させる従来の方針を維持します。

## 実マイクRMSに連動する4画面波形

録音中の4画面同期波形は、固定アニメーションではなく、同梱のローカルヘルパーがマイク入力から計算したRMS音量に合わせて振幅が変化します。波形は従来どおり4つの200×100ピクセル画面を1枚の800×100ピクセル表示として扱い、100ミリ秒ごとに更新します。

ヘルパーは音声入力中だけ起動し、音声入力が終わると停止します。マイク許可がない場合や入力デバイスを利用できない場合でも、Codexの音声入力処理とは分離して失敗し、Deckには最低限の細い波形を表示します。

## マイク権限とプライバシー

v0.4.9へ更新して最初に音声入力を開始すると、macOSからStream Deckまたは同梱の「Codex Shortcuts Plugin Microphone Meter」に対するマイク使用許可を求められる場合があります。実音量に連動する波形を使うには許可してください。Codex自身の録音と文字起こしには、別途Codexアプリのマイク権限も必要です。

同梱ヘルパーが扱うマイク音声は、RMS音量を計算するためだけに使用します。音声データをファイルへ保存せず、ネットワークや外部サービスへ送信しません。プラグイン本体へ渡すのも`0`から`1`の範囲へ変換した音量値だけです。2回目のダイヤル押下で送信されるのは、従来どおりCodexが文字起こししたテキストです。

## 継承する機能

4本の設定ダイヤルで共有する音声入力トグル、録音中のModel／Reasoning／Speed／Access回転ロック、開始前の待機中自動適用キャンセル、重複downイベント防止を維持します。録音していないときは、回転停止80ミリ秒後に設定を自動適用します。

## Agentキーのタスク名表示

表示中の6つのAgentキーは、それぞれ長いタスク名を100ミリ秒間隔・10ピクセル刻みで横へ流します。短い名前は静止表示し、選択中の外枠明滅と状態色は従来どおり維持します。

## 配布物

プラグインのバージョンは`0.4.9.0`です。同梱するStream Deck +プロファイルの各Actionも`0.4.9.0`へ更新し、配布アーカイブは`dist-v0.4.9-final`へ出力します。
