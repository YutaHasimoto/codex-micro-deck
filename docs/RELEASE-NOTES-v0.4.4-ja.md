# Codex Micro Deck v0.4.4 リリースノート

リリース日: 2026年7月26日

4本の設定ダイヤルすべてを、回して止めるだけで適用できるようにしました。

| ダイヤル | 停止後の自動適用 |
|---|---|
| Model | 350ミリ秒 |
| Reasoning | 350ミリ秒 |
| Speed | 350ミリ秒 |
| Access | 1.2秒 |

AccessはAsk、Delegate、Full、Customのどれも回転停止後に1回だけ適用します。Fullを回転操作で選んだ場合も、1.2秒の待機が終われば新規タスク既定と追跡タスクへ同期します。再回転、タップ、長押し、ダイヤルの非表示化は、まだ始まっていない待機中の適用を中止します。

物理ダイヤル押下は即時適用の補助操作として残しています。Fullを物理押下で即時適用する場合だけ、従来どおり4秒以内の2回押しが必要です。

v0.4.3で追加したAccess 4択のconfig.toml更新、Customの設定ファイル非変更、permission profileまたはsandboxの読み戻し検証は維持します。Reasoningの存在しない`Max`は引き続き候補にも送信値にも含めません。Accessのタッチ領域は盾とチェックのアイコンを維持します。

設定は現在実行中のターン途中では変わらず、次のターンから使われます。通常、CodexまたはStream Deckアプリの再起動は不要です。
