# Codex Shortcuts Plugin v0.4.10 リリースノート

## 終了操作の安全な1回再探索

Codexが音声入力終了時に入力欄を差し替える間、アクセシビリティツリーの応答が3.5秒を超えることがあります。v0.4.10では、「音声入力を停止」または「文字起こしして送信する」操作がこのタイムアウトになった場合に限り、現在の入力欄を1回だけ再探索します。

最初の操作がタイムアウト直前に届いていた場合、再探索はすでに表示されている「音声入力」ボタンを検出して終了済みとして扱い、録音を開始し直しません。開始操作は、遅れて届いた最初の押下と重複する危険があるため再試行しません。対象がない場合や複数ある場合も推測でキー入力せず、安全に失敗させます。

## マイク権限拒否を4画面へ表示

実マイクRMS用ヘルパーがマイク権限拒否を検出すると、録音波形の代わりに4つのダイヤル画面すべてをamberの「Allow Mic」表示へ切り替えます。開始に使ったダイヤルへalertを1回だけ表示し、開始ダイヤルを特定できない場合も表示中のダイヤル1つだけへalertを出します。

同じ音声入力session中はヘルパーを再起動しないため、5秒ごとの再試行、重複alert、同じ権限エラーの繰り返しを防ぎます。音声入力を終了するとこの抑制状態を解除し、次の音声入力sessionでは、設定変更後のマイク権限を改めて確認できます。

この表示は実音量波形用ヘルパーの権限状態を示します。Codex自身の音声入力とは分離されているため、RMSを取得できなくてもCodex側の録音・文字起こし操作は継続できます。ヘルパーは従来どおり音声を保存せず、外部へ送信しません。
