# Codex Shortcuts Plugin v0.3.1 リリースノート

リリース日: 2026年7月22日

v0.3.1では、設定ダイヤルの確定方法と、Codexデスクトップへの反映状態を分かりやすくしました。v0.3.0で導入した4つの役割と候補はそのままです。

## 3つのダイヤルを自動適用

Model、Reasoning、Speedは、ダイヤルの回転が止まって350ミリ秒後に自動で設定へ保存します。候補を連続して回している間は保存せず、最後に止まった値だけを適用します。待ち時間中にダイヤルを押すと、350ミリ秒を待たずに即適用します。

Approval levelは安全のため自動適用しません。回転中は未適用候補をアンバーで表示し、ダイヤルを押したときだけ確定します。

| 役割 | 回転停止350ミリ秒後 | ダイヤル押下 |
|---|---|---|
| Model | 自動適用 | 待たずに即適用 |
| Reasoning | 自動適用 | 待たずに即適用 |
| Speed | 自動適用 | 待たずに即適用 |
| Approval level | 未適用のまま | 選択候補を確定 |

新しい回転、押下、タップ、長押し、Encoderの非表示が発生した場合は、古い自動適用予約を取り消します。これにより、以前の候補が遅れて保存されることを防ぎます。保存に失敗した場合は警告を表示し、成功した値として扱いません。

## Codexへの反映タイミング

プラグインは設定を`~/.codex/config.toml`へ原子的に保存します。現在実行中の処理や既存タスクを途中から変更する機能ではありません。

- 保存した設定は新しいタスクで利用されます。
- 新しいタスクでも変わらない場合は、Codexデスクトップを再起動すると確実です。
- タッチ領域の表示は設定ファイルへの保存結果を示し、既存タスクへ即時反映されたことを意味しません。

この反映条件はModel、Reasoning、Speed、Approval levelに共通です。

## 保存成功が見える表示

保存に成功すると、物理Deckの値欄へ`✓ Saved`、補助表示へ`Saved · New task`を1.5秒間表示します。未適用を示すアンバーは解除され、役割ごとの通常色へ戻ります。1.5秒後は保存した実値を再表示します。

Property Inspectorには「保存済み。新しいタスクで反映、変わらなければCodex再起動」と表示します。これは設定ファイルへの保存完了を示すもので、既存タスクへ即時反映されたことを示す表示ではありません。

## アイコン中心の表示

8キーと4つのタッチ領域は、引き続き文字より大きなアイコンを中心に表示します。短い値の表示は補助情報として1行に限定し、状態は色と形の両方で区別します。
