# Codex Shortcuts Plugin v0.4.5 リリースノート

## 全設定ダイヤルを80ミリ秒へ統一

Model、Reasoning、Speed、Accessはすべて、最後の回転から80ミリ秒後に自動適用します。再回転、タップ、長押し、表示消滅、物理押下は、まだ開始していない待機中の適用を従来どおり取り消します。

Reasoningの候補はLow、Medium、High、XHigh、Ultraだけです。存在しないMaxは表示も送信もしません。AccessのFullも回転操作では80ミリ秒後に適用し、物理押下で即時適用するときだけ4秒以内の2回押し確認を維持します。

## Codex画面と永続設定を速く同期

follow中のタスクには、同じ設定patchを常設Desktop IPCへ先に送って画面反映を開始します。その後、1つのCodex App Serverを共有して最大6タスクの次ターン設定を永続化し、各タスクで`thread/resume`、`thread/settings/update`、読み戻し検証の順を守ります。

異なるタスクの処理だけを並列にしたため、遅い1タスクがほかのタスクの開始を待たせません。Desktop IPCは補助経路なので失敗してもApp Serverの永続化成功を妨げません。一方、App Serverの失敗や読み戻し不一致は従来どおり`⚠ X/N`またはエラーで正直に示します。

設定バッチは完了前にDesktop IPCの結果も待つため、後のダイヤル操作が先行する古いpatchで上書きされることはありません。現在実行中のターンを途中で変更せず、確定した設定は各タスクの次ターンから使用されます。
