# Codex Shortcuts Plugin v0.4.11 リリースノート

## マイク権限をStream Deckへ帰属

実マイク音量に連動する波形用ヘルパーから、独立アプリとして認識される埋め込み`Info.plist`と固有のコード署名identifierを外しました。ヘルパーはStream Deckプラグインが直接起動する単一の子プロセスとして動作し、macOSのマイク権限は署名済みのStream Deck本体へ帰属します。

これにより、システム設定の「プライバシーとセキュリティ」→「マイク」でStream Deckを許可した状態を、波形のRMS音量取得にも使える構成になります。Codex自身の録音・文字起こしには、引き続きCodexアプリ側のマイク権限が必要です。

ヘルパーは音声入力中だけ起動し、マイク音声から表示用のRMS音量だけを計算します。音声データは保存も外部送信もせず、音声入力を終了すると停止します。

## 検証

独立したアプリidentityが再び混入しないよう、ビルド定義にアプリ用`Info.plist`の埋め込み、固有のコード署名identifier、`.app`形式が含まれていないことを`npm run validate`で確認します。

## 配布物

プラグインのバージョンは`0.4.11.0`です。同梱するStream Deck +プロファイルの各Actionも`0.4.11.0`へ更新し、配布アーカイブは`dist-v0.4.11-final`へ出力します。
