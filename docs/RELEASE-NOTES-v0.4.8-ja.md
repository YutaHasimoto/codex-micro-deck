# Codex Micro Deck v0.4.8 リリースノート

## 4本共通のダイヤル音声入力

Model、Reasoning、Speed、Accessのどのダイヤルでも、物理押下1回でCodexの音声入力を開始します。もう一度いずれかの設定ダイヤルを押すと、Codex自身の「文字起こしして送信する」操作を実行します。開始したダイヤルと終了するダイヤルは同じでなくても構いません。

Codexの音声入力は、macOSアクセシビリティ経由で英語／日本語のボタン名へ完全一致して操作します。開始は`Dictate`／`音声入力`、送信は`Transcribe and send`／`文字起こしして送信する`です。停止後にReturnキーを追加送信しないため、文字起こし結果を重複送信しません。

旧互換のComposer／Voiceダイヤルは、押している間だけ録音し、解放時に文字起こし結果を入力欄へ挿入する従来のpush-to-talk動作を維持します。

## 4画面を横断する録音波形

録音中は通常の背景、アイコン、値を隠し、Stream Deck +の4つの200×100ピクセル画面を横断する波形を表示します。共通の800×100ピクセル波形から、各画面へ`0／200／400／600`ピクセル位置の領域を切り出すため、4画面が同じフレームでつながります。100ミリ秒ごとに更新し、音声入力が終わると透明レイヤーで波形を消して通常表示へ戻します。

この波形は録音中であることを示すアニメーションです。プラグインはマイクの実音量を取得せず、音声を録音・保存しません。実際の録音と文字起こしはCodexが行います。

## 録音中の誤操作防止

音声入力を開始する前に、4本すべてのダイヤルで待機している80ミリ秒自動適用を中止します。録音中はModel、Reasoning、Speed、Accessの回転を無効にし、左右回転へ設定したカスタムショートカットも実行しません。ダイヤル押下中にStream Deckから同じdownイベントが重複して届いても、開始直後に送信へ反転しないよう無視します。

録音していないときの設定変更は従来どおりです。各候補は回転停止80ミリ秒後に自動適用され、新規タスクの既定値と追跡中Agentタスクの次ターン用設定へ同期します。v0.4.8では設定ダイヤルの物理押下を即時適用に使いません。

## 権限と失敗時の動作

音声入力には、macOSのアクセシビリティ／オートメーション権限とCodex自身のマイク権限が必要です。Property Inspectorの「Codexへの画面・キー操作を有効にする」がOFFの場合も開始しません。開始に失敗した場合は通常表示のまま、送信に失敗した場合は録音状態を保ち、再試行できるようにします。

状態表示、Agentタスクを開く操作、承認／却下、設定ダイヤルの回転・タップ・長押しは、画面・キー操作をOFFにしても従来どおり利用できます。

## 継承する機能

v0.4.7までのAgentキーのタスク名1行表示、選択中マーキー、状態色と形、Standard速度の`null`／`"default"`同値検証、follow中タスクへのDesktop IPC先行反映、最大6タスクのApp Server並列同期と読み戻し検証を維持します。

## 配布物

プラグインのバージョンは`0.4.8.0`です。既存のv0.4.7配布アーカイブは残し、v0.4.8は`dist-v0.4.8-final`へ出力します。
