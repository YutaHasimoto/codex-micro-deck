# Codex Micro Deck v0.4.6 リリースノート

## Agentキーにタスク名を表示

6つのAgentキーすべてにタスク名を1行表示します。短い名前は静止表示し、長い名前は通常時に末尾を`…`で省略します。選択中の長い名前だけ、100ミリ秒間隔・10ピクセル刻みで横へ流します。

ロボットアイコン、右上の1〜6の番号、右下の形つき状態アイコン、状態色、選択中の外枠は従来どおり維持します。タスクIDは表示しません。

Unicodeの複合文字を途中で分割せず、XML特殊文字もエスケープしてキー画像へ描画します。

## v0.4.5から継承する機能

Model、Reasoning、Speed、Accessの4ダイヤル、80ミリ秒の自動適用、最大6タスクへの同期と読み戻し検証はv0.4.5と同じです。

## 配布物

プラグインのバージョンは`0.4.6.0`です。v0.4.5の配布アーカイブは残し、v0.4.6は`dist-v0.4.6-final`へ出力します。
